# ByteExecutor

A comprehensive Android and payload project structure.

## Project Structure

```
ByteExecutor/
├── app/                    # Android application
├── payload/               # Native payload library
├── build.gradle           # Project build configuration
├── settings.gradle        # Project settings
└── patch_roblox.py       # Roblox patcher utility
```

## Features

- Android application with Material Design
- Native C++ integration
- Lua scripting engine
- Script Hub activity for managing scripts

## Getting Started

1. Clone the repository
2. Open in Android Studio
3. Build the project
